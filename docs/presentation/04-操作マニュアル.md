# 操作マニュアル

## 1. はじめに

本マニュアルは、発表用ブラウザ版を操作する講師と専任職員を対象とする。画面に表示される日本語ラベルをそのまま記載し、迷ったときの戻り先とエラー対応を併記する。

> **重要：** 操作できる範囲はアカウントのロールと状態で決まる。スマートフォンでは管理系の変更操作を行わず、パソコンを利用する。

## 2. ログイン・パスワード

1. `/login`を開く。
2. 「メールアドレス」「パスワード」を入力し、「ログイン」を押す。
3. 初回アカウントで「パスワード変更」が表示された場合は、新しいパスワードを入力して保存する。
4. パスワードを忘れた場合は「パスワードをお忘れですか？」を開き、登録メールアドレスと氏名を添えて教務担当へ連絡する。専任職員が本人確認後に再設定メールを送信する。
5. 利用停止・退職済みアカウントはログインできない。専任職員へ状態確認を依頼する。

実装根拠：`apps/web/components/login-form.tsx`、`apps/web/src/routes.tsx:77`、`apps/api/src/authorization.ts:34-59`。

## 3. 講師向け：成績入力・保存

### 3.1 科目を開く

1. ログイン後の「担当科目」画面で年度を確認する。
2. 科目カードの「成績表を開く」を押す。
3. 「前期」「後期」の表示を確認する。確定済み学期は編集できない。

### 3.2 評価比重を設定する

1. 「評価比重」を確認する。
2. 出席率・平常点・課題点の比重を整数で入力する。
3. 合計が100になることを確認し、「初期比重を保存」または保存ボタンを押す。
4. 「評価比重を保存しました。成績を再計算しました。」が表示されれば完了。

### 3.3 成績を保存する

1. 学生ごとに「出席率」「平常点」「課題点」を入力する。
2. 出席率は0〜100、平常点・課題点は1〜10で入力する。未入力は空欄のままにできる。
3. 「変更を保存」を押す。
4. 「成績を保存しました。」を確認する。画面を更新して値が残っていることを確認する。

エラー時は、赤字の項目名と範囲を直してから再度保存する。確定済み、担当外科目、過去年度の場合は専任職員へ連絡する。

## 4. 専任職員向け：確定・再開・修正

### 4.1 成績を確定する

1. `/admin`を開き、「科目別の確定状況」を確認する。
2. 対象科目の入力人数と学期を確認する。
3. 「確定する」を押し、確認ダイアログで同意する。
4. 「○○の前期を確定しました。」を確認する。

確定後は講師の通常編集を止める。確定操作は現在年度のみ実行できる。

### 4.2 成績を再開する

1. 確定済み科目の「再開する」を押す。
2. 再開理由を具体的に入力し、確認する。
3. 「再開しました。」を確認する。

再開理由は空欄や空白だけでは受け付けない。操作履歴には「成績再開」として残る。

### 4.3 成績を修正・再試験登録する

1. `/admin/grades`で年度、学期、学年、科目、学生を絞り込む。
2. 対象行の「詳細・修正」を押す。
3. 修正値と「理由」を入力する。
4. 「最新成績を修正」または「再試験を登録」を押す。
5. 履歴に回数と評価が追加されたことを確認する。

## 5. 専任職員向け：マスタメンテナンス

### 学生

「学生を登録・確認する」で「学生を登録」を選び、学籍番号、氏名、氏名カナ、生年月日、コース、入学年度を入力する。性別は画面では入力せず「未回答」として登録される。登録済み学籍番号は重複できない。在籍状態変更では、状態・適用年度・変更理由を入力する。

### 講師・専任職員

講師管理では「講師を登録」、専任職員管理では「専任職員を登録」を押し、氏名とメールアドレスを入力する。登録後に表示される一時パスワードは対象者へ安全な方法で渡す。再設定が必要なときは、専任職員が対象者を確認して再設定メールを送信する。画面を閉じた後に一時パスワードを再表示できない場合がある。

### 科目・年度

「今年度の科目を管理する」で科目名、学年、担当講師、対象コースを指定する。確定済みまたは過去年度の科目は変更できない。「現在年度を設定する」では対象年度を確認してから切り替える。

## 6. 通常CSV取込

1. パソコンで「通常CSV取込」を開く。
2. CSVの種類を選択する。科目CSVの場合は対象学年も選択する。
3. UTF-8のCSVを選び、「内容を確認する」を押す。
4. 件数とエラー行を確認する。エラーがある場合はCSVを修正し、再読込する。
5. 問題がなければ「反映する」を押す。
6. 一時パスワードが表示された場合は「一時パスワードCSVを保存」で安全な場所へ保存し、保存後に画面を閉じる。

確認前はDBへ反映されない。同じ取込を再送しても重複しない。CSVにない学生は変更されない。

## 7. 成績CSV／PDF出力

1. 「成績出力」を開く。
2. 「出力パターン」「年度」「学期」「出力形式」を選ぶ。
3. 「件数を確認する」を押し、確定済み件数を確認する。
4. CSVなら「CSVをダウンロード」、PDFならPDF出力操作を行う。
5. ダウンロード後、対象年度・学期・科目の内容を確認する。

出力確認が期限切れの場合は、再度「件数を確認する」からやり直す。実際の印刷機での改ページ・文字切れは発表前に別途確認する。

## 8. 年度更新

年度更新は専任職員がパソコンで行う。新年度入力と、講師CSV・1〜3年科目CSV・新入生CSVの5CSVを順番に入力する、計6工程である。「全体を確認する」で卒業候補、講師、新入生、科目件数とエラーを確認し、「一括反映する」を押す。反映後は「現在年度を設定する」、学生一覧、科目一覧、監査履歴で結果を確認する。

途中で入力内容を変更した場合は確認結果が無効になる。反映失敗時は入力内容を保持したまま、エラー表示を確認して再実行する。同じ確認済みキーの再送は重複登録を避ける。

## 9. 監査・ログアウト・無操作

- 「監査履歴」では操作種別、操作者、対象、日時を絞り込める。
- 取込・年度更新の履歴では処理状態と対象年度を確認できる。
- 個人情報、パスワード、確認トークンは監査画面に表示しない。
- 操作を終えたらメニューの「ログアウト」を押す。
- 一定時間操作しない場合は自動ログアウトされる。入力途中の内容は保存操作を行ってから離れる。

## 10. スマートフォン利用

スマートフォンでは講師の成績確認など閲覧を優先し、成績保存・確定・取込・出力・年度更新などの変更操作は行わない。画面に「スマートフォンでは閲覧のみです。」と表示された場合は、パソコンへ切り替える。

## 11. トラブルシューティング

| 表示・症状 | 対応 |
|---|---|
| ログインできない | メールアドレス・パスワードを確認し、再設定を依頼する。アカウント状態も確認する |
| パスワード変更画面から進めない | 新旧パスワードの入力条件を確認し、保存後に再ログインする |
| 「権限がありません」 | 講師／専任職員のアカウントを確認し、担当科目・対象年度を確認する |
| 「確定済み」 | 専任職員が理由を記録して再開するまで、講師は編集しない |
| CSVのエラー行が表示される | 指定された行・項目を修正し、UTF-8で保存して再確認する |
| 出力確認が期限切れ | 件数確認をやり直す。古いURLやトークンを再利用しない |
| 通信に失敗した | 再読込前に保存済みか確認し、複数回の二重送信を避ける。監査履歴で結果を確認する |
| 画面が操作不能 | 無操作ログアウトやセッション切替の可能性があるため、ログインし直す |

## 12. 問い合わせ時に伝える情報

画面名、操作日時、対象年度・学期、表示された日本語メッセージ、再現手順を伝える。パスワード、一時パスワード、確認トークン、学生の個人情報はチャットやメールに貼り付けない。
